Git keeper - 

As the Git Keeper i was responsible for managing our Git workflow. I helped organise branches for people to work out of and once a branch was complete I would merge it. sometime there was merge conflicts and I would fix them up and ensure they were working as intended and on time for the project to continue at a rate that suited the group. This helped the team collaborate efficiently and reduced the risk of losing work or introducing errors that would cost more time and issues down the line. 

I really enjoyed this as I was able to look at the work everyone had done and see how the project came together all at one point and been the git keeper I was the one ensuring the branches were done correctly

I learned how important it is to have someone that sits at the center of the all the branches and information from the team i felt this was a very crucial role and important to a project and that if this role was not a thing people would be pushing work and it might override other peoples work and creating more issues for the project and the team working together.
